# 商品取图规则匹配引擎 (Goods Picture Matcher)

## 概述

本 Skill 根据取图参数 JSON 和候选图片名称列表，按照预定义规则进行多步骤过滤与打分，最终返回最佳匹配的图片名称。若无法匹配则返回 `"无"`。

---

## 输入格式

### 取图参数 (params) - JSON Object

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `渠道` | string | 否 | 销售渠道，如"天猫"、"京东" |
| `销售类目` | string | 否 | 商品所属类目，如"家具" |
| `图片类型` | string | 否 | 图片类型，规则要求为 `"sku小图"`，当前版本仅作记录不做过滤 |
| `型号` | string | **是** | 所有型号，多个型号可用逗号/顿号/空格分隔。如 `"RQ3R-A, LS387S10-D"` 或 `"RQ3R-A"` |
| `颜色` | string | 否 | 颜色关键词，多个可用逗号/顿号/空格分隔。如 `"实木面"` 或 `"黑色, 白色"` |
| `功能` | string | 否 | 功能关键词，如 `"伸缩"` |
| `规格` | string | 否 | 规格关键词，如 `"1.3m"` |
| `子项` | array | 否 | 子项列表，每个子项包含名称、数量、张数。如 `[{ "名称": "餐桌", "数量": "1", "张数": "2" }]`。当前版本仅作记录，不参与匹配 |

### 图片名称列表 (imageNames) - Array of Strings

每张候选图片的完整名称字符串。如：
```
RQ3R-A组合-主图-1.3m伸缩餐桌-实木面+LS387S10-D餐椅x4-SKU-(1).jpg
```

## 匹配算法

### 总体流程

```
输入: params (JSON), imageNames (Array)
输出: 最佳图片名称 (String) 或 "无"

Step 1: 图片类型校验
Step 2: 型号完全对应过滤
Step 3: 颜色/功能/规格关键词打分
Step 4: 返回结果
```

---

### Step 1：图片类型校验

- 检查 `params.图片类型` 是否为 `"sku小图"`
- **V1 版本**：仅校验记录，不基于图片名称过滤。因为图片类型信息通常不在图片名称中，实际过滤应在上游 CMS/图库系统中完成
- 若未来图片名称中出现类型标识（如 `-SKU-` 后缀），可在此步骤增加过滤逻辑

**输出**：所有图片名称进入 Step 2（候选集不变）

---

### Step 2：型号完全对应过滤

这是最关键的过滤步骤。

#### 2.1 解析入参型号集合

从 `params.型号` 中提取所有型号：
- 分隔符：`,` `，` `、` 空格
- 去除空白和空值
- **全部转为大写**（大小写不敏感）

```
输入型号集合 = 型号.split(分隔符)
全部做大写归一化
```

#### 2.2 从图片名称中提取型号

使用正则表达式从图片名称中提取所有型号：

```
/[A-Z]{2,}\d+([A-Z]*\d+)*[A-Z]*-[A-Z\d]+/gi    (大小写不敏感匹配)
```

**正则说明**：
- `[A-Z]{2,}` — 至少 2 个大写字母开头（排除 `x4` 这类单字母误匹配）
- `\d+` — 至少 1 个数字
- `([A-Z]*\d+)*` — 可选：0 或多段 "字母+数字"（如 `S10`、`EF789`），支持 `LS387S10-D` 这类型号
- `[A-Z]*` — 可选：结尾字母段（如 `RQ3R-A` 中连字符前的 `R`）
- `-` — 必须有一个连字符
- `[A-Z\d]+` — 至少 1 个字母或数字结尾

**型号示例**：`RQ3R-A`、`LS387S10-D`、`ABC123-X`、`AB12CD34-G`

提取后去重，全部转为大写。

#### 2.3 完全对应判定

对于每张图片，判定：
- 图片名中的型号集合 **与** 入参型号集合 **完全一致**
- 即：`图片型号集合 === 入参型号集合`（元素数量相同、每个元素都对应相等）
- **不允许图片名中多出型号**（extra models）→ 淘汰
- **不允许入参型号在图片名中缺失**（missing models）→ 淘汰

#### 2.4 过滤结果

- 通过完全对应判定的图片 → 进入 Step 3
- **如果入参中未指定任何型号** → 跳过此步骤，所有图片进入 Step 3
- **如果过滤后无候选图片** → 直接返回 `"无"`

---

### Step 3：颜色/功能/规格关键词匹配打分

对上一步的候选图片，用 `颜色`、`功能`、`规格` 三个字段的关键词进行匹配打分。

#### 3.1 关键词解析

每个字段的关键词以逗号/顿号/空格分隔：

```
颜色关键词列表 = params.颜色.split(/[,，、\s]+/)
功能关键词列表 = params.功能.split(/[,，、\s]+/)
规格关键词列表 = params.规格.split(/[,，、\s]+/)
```

#### 3.2 打分规则

对每张候选图片：
- 遍历颜色关键词 → 若图片名中包含该关键词（大小写不敏感），颜色得分 +1/关键词
- 遍历功能关键词 → 若图片名中包含该关键词（大小写不敏感），功能得分 +1/关键词
- 遍历规格关键词 → 若图片名中包含该关键词（大小写不敏感），功能得分 +1/关键词
- **总分 = 颜色得分 + 功能得分 + 规格得分**

#### 3.3 选择最优图片

- 取 **总分最高** 的图片作为最终结果
- 若多张图片得分相同 → 取第一个遇到的最高分图片（遍历顺序）
- 若最高分为 0 → 仍返回该图片（已通过型号过滤，关键词未命中）

#### 3.4 边界情况

| 场景 | 处理方式 |
|------|----------|
| 颜色/功能/规格均为空，候选 > 1 | 返回候选列表最后一张图片 |
| 颜色/功能/规格均为空，候选 = 1 | 直接返回该唯一候选 |
| 候选列表为空 | 返回 `"无"` |
| 有候选但关键词均为空 | 返回候选列表最后一张 |

---

### Step 4：返回结果

- 匹配成功 → 返回最佳图片名称字符串
- 无匹配 → 返回字符串 `"无"`

## 完整匹配示例

### 输入

**取图参数**：
```json
{
  "渠道": "天猫",
  "销售类目": "家具",
  "图片类型": "sku小图",
  "型号": "RQ3R-A, LS387S10-D",
  "颜色": "实木面",
  "功能": "伸缩",
  "规格": "1.3m",
  "子项": [
    { "名称": "餐桌", "数量": "1", "张数": "2" },
    { "名称": "餐椅", "数量": "4", "张数": "2" }
  ]
}
```

**图片名称列表**：
```
RQ3R-A组合-主图-实木面-SKU-(1).jpg
RQ3R-A组合-主图-1.3m伸缩餐桌-实木面+LS387S10-D餐椅x4-SKU-(1).jpg
RQ3R-A组合-主图-1.3m伸缩餐桌-实木面-SKU-(2).jpg
RQ3R-B组合-主图-1.3m伸缩餐桌-实木面+LS387S10-D餐椅x4-SKU-(1).jpg

RQ3R-A+LS387S10-D-白图-SKU-(1).jpg
```

#### Step 2：型号完全对应

| 图片 | 提取型号 | 入参型号 | 结果 |
|------|----------|----------|------|
| RQ3R-A组合-主图-实木面-SKU-(1).jpg | [RQ3R-A] | [RQ3R-A, LS387S10-D] | ❌ 缺 LS387S10-D |
| RQ3R-A组合-主图-1.3m伸缩餐桌-实木面+LS387S10-D餐椅x4-SKU-(1).jpg | [RQ3R-A, LS387S10-D] | [RQ3R-A, LS387S10-D] | ✅ 完全对应 |
| RQ3R-A组合-主图-1.3m伸缩餐桌-实木面-SKU-(2).jpg | [RQ3R-A] | [RQ3R-A, LS387S10-D] | ❌ 缺 LS387S10-D |
| RQ3R-B组合-主图-1.3m伸缩餐桌-实木面+LS387S10-D餐椅x4-SKU-(1).jpg | [RQ3R-B, LS387S10-D] | [RQ3R-A, LS387S10-D] | ❌ 缺 RQ3R-A 多 RQ3R-B |
| RQ3R-A细节-1.3m伸缩餐桌-实木面-SKU-(3).jpg | [RQ3R-A] | [RQ3R-A, LS387S10-D] | ❌ 缺 LS387S10-D |
| RQ3R-A组合-主图-1.3m伸缩餐桌-大理石面+LS387S10-D餐椅x4-SKU-(1).jpg | [RQ3R-A, LS387S10-D] | [RQ3R-A, LS387S10-D] | ✅ 完全对应 |
| RQ3R-A+LS387S10-D-白图-SKU-(1).jpg | [RQ3R-A, LS387S10-D] | [RQ3R-A, LS387S10-D] | ✅ 完全对应 |

候选图片缩减为 3 张：
1. `RQ3R-A组合-主图-1.3m伸缩餐桌-实木面+LS387S10-D餐椅x4-SKU-(1).jpg`
2. `RQ3R-A组合-主图-1.3m伸缩餐桌-大理石面+LS387S10-D餐椅x4-SKU-(1).jpg`
3. `RQ3R-A+LS387S10-D-白图-SKU-(1).jpg`

#### Step 3：关键词打分

| 图片 | 颜色(实木面) | 功能(伸缩) | 规格(1.3m) | 总分 |
|------|:----------:|:--------:|:--------:|:----:|
| 图片1 (实木面...) | 1 | 1 | 1 | **3** |
| 图片2 (大理石面...) | 0 | 1 | 1 | 2 |
| 图片3 (白图) | 0 | 0 | 0 | 0 |

#### Step 4：输出

```
最佳图片：RQ3R-A组合-主图-1.3m伸缩餐桌-实木面+LS387S10-D餐椅x4-SKU-(1).jpg
得分：3分
```

## 注意事项

1. **型号格式假设**：当前正则假设型号为 `字母+数字+字母-字母数字` 格式（如 `RQ3R-A`）。若遇其他格式（如无连字符的 `ABC123`），需要扩展正则
2. **关键词匹配**：使用 `includes` 子串匹配，可能产生误匹配（如关键词 "红" 匹配到 "分红"）。后续可考虑使用词边界匹配
3. **图片类型过滤**：V1 版本中 `图片类型=sku小图` 不参与图片名过滤。该过滤应在调用本 Skill 之前的上游系统完成
4. **对比时统一大写**：型号匹配时所有型号归一化为大写，大小写不敏感
5. **分隔符灵活性**：型号和关键词支持多种分隔符：`,` `，` `、` ` `（空格）

## 实现文件

- **核心引擎**：`goods_pic_matcher.js` — 纯逻辑模块，无 DOM 依赖，可同时在浏览器和 Node.js 中使用
  - 浏览器：`<script src="goods_pic_matcher.js"></script>` → 挂载到 `window.GoodsPicMatcher`
  - Node.js：`const { matchPictures } = require('./goods_pic_matcher.js');`
  - 修改匹配规则只需修改此一个文件
- **可视化验证**：`goods_pic_matcher.html` — 前端页面，引入 `goods_pic_matcher.js`，仅负责 UI 展示和人工验证
  - 在浏览器直接打开，输入 JSON 参数和图片名称即可看到每步匹配过程
